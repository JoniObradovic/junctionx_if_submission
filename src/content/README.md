# Scenario content

`scenarios/` contains the four situations and their source records.
`experience.js` contains fictional audiences, insurance portfolios and staff data.
`index.ts` exports canonical configuration and localized content.

Editorial fields use `{ fi, en }` on the owning record. Shared interface labels
live in `../locales/catalogue.ts`. IDs and rule values are language independent.

Source records include URLs, checked dates, applicable sections and limitations.
Keep those boundaries attached to the claims they support. Unknown coverage and
claim-success rates remain unknown; illustrative rewards and introductory pet help
remain proposals. Emergency guidance takes precedence over eligibility and tasks.

The reference-link index is in the [project README](../../README.md#resources-used).
