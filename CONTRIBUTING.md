# Contributing

Use the pinned Node version and `npm ci`. Keep changes focused and run
`npm run check`, followed by `npm run test:e2e` for interaction changes. Browser
binaries and OS libraries are developer dependencies, never published assets.

Use fictional data only. Preserve unknown values and evidence limitations. A
preventive action must not imply guaranteed coverage, claim acceptance or clinical
safety. Emergency routing takes precedence over service access and rewards.

Keep rule changes separate from copy/layout changes. Add independent boundary
expectations when calculations or state transitions change. Review both languages,
all relevant portfolios and keyboard behavior. Update source metadata when factual
copy changes. Never put agent tooling, secrets or generated reports in this repo.
